# 隐藏行为检查

SWE-smith 的 verifier 跑的是仓库自带的测试。它们覆盖了注入 bug 的主要症状，但不一定覆盖原函数的全部行为：对照注入 bug 之前的源码复核时，有约 10% 到 15% 的通过补丁没有恢复原有行为（`docs/TECH_REPORT.md` §3）。

这里每个文件对应一道这样的题，文件名就是 SWE-smith 的实例 ID。文件内容是普通的 Python 断言，写的是原函数在那些补丁出错的地方应有的行为，例如 `FrozenDict.clear()` 必须报错、`utcoffset(None)` 必须返回偏移量。

- **有效性**：每个检查都必须在注入 bug 之前的源码上通过；`scripts/regrade_hidden.py` 会先验证这一点，不通过的检查不参与评分。
- **用法**：`scripts/regrade_hidden.py` 把每个通过补丁应用到带 bug 的代码上，用该题自己的解释器运行检查（在 GPU 主机上以 `nobody` 运行，有超时）。
- **范围**：这些检查是事后根据已经观察到的补丁写的，用来把人工判断变成可执行、可复现的检查，并给今后的 verifier 补上这几处覆盖；不改变已经冻结的各轮结论。
